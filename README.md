# org-github — source for `koyu-labs/.github`

The org-wide defaults GitHub applies to every Koyu repo that has no file of its own: issue forms, the PR template
and CONTRIBUTING. This folder is the source; `koyu-labs/.github` is the published copy. Edit here, then publish:

```bash
org-github/publish.sh        # from the koyu-labs repo root; needs gh authenticated with push to koyu-labs/.github
```

Conventions these files encode: `docs/guides/repo-conventions.md`.
